# 使用指南

[文件入口](../README.md) · [安裝與啟動](getting-started.md)

## 登入與教材庫

註冊或登入後，從「我的教材」開啟教材。Email 不分大小寫，密碼長度為 15–128 個字元；帳號功能限制見 [限制](limitations.md)。教材與已保存的學習紀錄可在重新登入或更換瀏覽器後接續。

## 上傳與分析

1. 選取一份或多份文件，檢查來源順序、轉換狀態與 PDF 預覽。
2. 轉換失敗時重試或移除問題檔案；全部選定來源就緒後，點「開始分析教材」。
3. 分析完成後開啟地圖；部分結果或需要複核的內容應對照原文。

關閉頁面不會取消伺服器工作。分析失敗時可重試保存的進度；若要換檔，回來源頁移除失敗來源、加入替代檔案，再開始分析。只被失敗或已取消工作引用的來源可退出清單；正在分析或已用於發布結果的來源受保護。

支援格式、容量與定位精度見 [教材處理](materials.md)。

## 地圖與來源

地圖顯示選定觀念附近的兩層關係；搜尋與學習導覽可找到其他觀念。畫布範圍不影響完整知識結構。

觀念詳情提供重點、來源與學習入口，手機以對話框呈現。來源可開啟 PDF 對應頁或下載原檔；瀏覽地圖、來源或「複習重點」不會生成題目。

## 概念卡

從知識地圖的「建立概念卡」或側邊導覽「概念卡」進入。選擇已完成分析的教材，勾選概念、填寫卡組名稱，再點「保存並開始複習」。同一份教材可保存多個卡組。

每張卡正面是概念，背面是已發布的教材重點，可展開查看來源。支援上一張／下一張、翻面、洗牌；電腦可用方向鍵切換與空白鍵翻面。長重點保留全文，可在卡片內捲動閱讀。

建立或管理卡組時，可點「幫我選卡」，選擇「優先複習弱點」或「依學習路徑」及最多張數。先查看候選與推薦理由，按「套用推薦」後才取代目前勾選，仍可手動調整。保存會保留選取順序，之後手動加入的概念接在後面。

推薦只讀取同一教材版本的學習紀錄。弱點不足時不補入其他概念；沒有此版本的學習紀錄時，明確改從教材路徑起點推薦。路徑模式從目前位置接續尚未掌握的概念，必要時回到前段；全部已掌握或沒有弱點時可手動選卡。進度讀取失敗時保留手選功能，不把失敗當成沒有學習紀錄。推薦與套用均不更新學習掌握度，已保存的卡組不會自動隨進度改動。

卡組保存於帳號，重新登入後可從列表重開。教材更新後仍保留建立時的內容與來源；刪除卡組不刪教材。從列表「⋯」選單的「管理卡組」調整名稱與所選概念並保存；概念內容與來源沿用建立時的教材版本。瀏覽卡片不改變學習掌握度，不提供記憶追蹤或間隔複習。

## 題組與補強

從觀念詳情進入學習，再明確開始題組。題數依可出題重點決定，準備中可離開頁面後接續；不同觀念各自保存題組。

選完已發布題目後整組交卷，查看評分、說明與來源。尚未交卷的選取不會保存；交卷回應遺失時查回結果，版本衝突時先同步再確認重送。

有錯題時，閱讀來源後點「開始補強」。補強只針對仍待改善的重點，不會自動無限出題。補強答對代表這次練習改善，不等於長期掌握；規則見 [學習與評量](learning.md)。

刷新或重新登入會恢復已保存題組與結果。結果頁提供接續練習、下一個觀念或完成操作。

## 更新與刪除

教材可重新命名或追加來源。追加會建立新地圖版本；失敗或取消更新時，已發布地圖與學習紀錄仍可讀。來源與內容未變且能唯一對應的重點，可承接作答證據。

刪除整份教材會移除其來源、地圖、概念卡組、題目與學習紀錄，須在畫面確認；有工作進行時會先保存刪除意圖，再完成清理。

## Podcast

從「我的教材」各教材內的「概念卡／Podcast」入口可查看、建立及管理該教材的內容；外層原有「概念卡／Podcast」入口顯示帳號全部內容，首頁不新增卡組或 Podcast 區塊。教材內「知識地圖／概念卡／Podcast」以同層導覽切換，清單、查看內容、管理與建立都保留教材工作區及頁籤。從帳號總列表開啟卡組或 Podcast，也會進入所屬教材工作區。兩邊共用改名與刪除操作。教材入口會帶入教材，開啟已保存內容後返回也保留教材範圍；帳號入口建立時先選教材。知識地圖仍提供直接建立入口。建立 Podcast 的「幫我選概念／選擇概念／講解設定」各自獨立，手機可直接切換三區且保留設定。可搜尋後批次選取、只看已選，或依弱點／學習路徑推薦；沒有同版本學習紀錄時會明示使用教材路徑。

輸入名稱，選擇「快速複習」或「完整講解」，並選擇「雙人對談」或「單人解說」後開始生成。新講稿會用必要的情境、比喻或提問協助理解，技術事實仍須符合教材。內容較多會自動拆集，所有選定重點都保留。生成頁顯示目前集數與「整理內容 → 製作音訊 → 完成」階段，不顯示內部逐字稿狀態。生成期間可以離開頁面，進度與已完成內容會保存；全部分集完成後可播放。失敗或取消後使用「接續生成」，保留已保存的逐字稿及音訊。

播放器提供播放／暫停、時間軸、前後 10 秒、上／下一集及音量／靜音。播放器主控制置中，手機將音量與設定排在第二列。倍速選單只調整 0.5–2 倍速；「自動接續」在播放器上直接切換。已移除 K／J／L／M 自訂快捷鍵。也可從分集清單直接選擇。重開時恢復這個帳號在同一瀏覽器的播放位置，不會自動播放。播放器下方以同一功能區的「逐字稿／本集重點」頁籤切換，預設顯示當前集數的已保存逐字稿，雙人對談標示學習者／講解者，單人標示旁白，供試聽對照與精修。音訊尚未生成時也可讀取已保存文字；切換集數會同步換稿。教材重點保留在同區的另一頁籤。教材後來更新，不會改寫既有 Podcast 的版本。

Podcast 列表可從「⋯」管理選單重新命名或刪除；重新命名與「我的教材」、概念卡相同，在原位置直接編輯，使用「取消／儲存」，不另開彈窗。刪除前需確認。生成／播放頁不放管理選單。刪除只移除該 Podcast 的逐字稿、音訊及本機播放位置；原教材仍保留。登出或換帳號會停止播放。聽完不會直接更新學習掌握度。Podcast 畫面不顯示「教材內容待核對」提示，後端來源核對與失敗處理仍保留。既有音訊保持原樣，新建立內容才套用新的講解方式。

## 教材語音問答與補充學習

教材內提供「語音問答」及「補充學習」按鈕。

語音問答只使用開啟對話時的這份教材版本。可直接打字，或點擊開始錄音／停止錄音，修改辨識文字後送出。文字回答先顯示，語音完成後可播放；回答附來源入口。對話保存在帳號中，可重開、刪除、取消正在處理的問題及重試失敗部分。原始錄音處理後移除，不長期保存。每次錄音最多兩分鐘；尚未提供連續監聽或插話打斷。對話不更新掌握度或作答紀錄。教材更新後，舊對話保留原引用，要使用新內容請開新對話。

補充學習可選課程複習或自主學習，輸入補充需求，搜尋學術論文與官方教學。目前學術 metadata 使用 OpenAlex，官方教學索引為 Python 官方文件與 MDN Web Docs；明示可取得的 CC BY／CC0 PDF 、PSF 文件或附同授權要求的 MDN 文件才提供自動匯入。候選顯示作者、版本、授權與來源。未能核對全文或授權者仍可查看原始來源，不以摘要冒充全文。搜尋分頁載入，選取數量不設上限，逐份下載與轉換。

先「取得選取來源」，文件準備好後勾選不可逆確認，再「確認加入教材」。分析沿用原教材流程，成功後更新知識地圖，不提供切回純課程版本的入口。既有卡組、Podcast 與對話的固定來源仍保留。搜尋與取得狀態可重開，失敗逐項顯示；教材被其他操作更新時拒絕直接追加舊意圖，不偷偷合併。

## 從主題建立教材

首頁「從主題建立教材」可輸入想學的內容。系統先提出學習程度、目標、涵蓋及排除範圍，可直接修改；按下「確認範圍並搜尋」後才搜尋學術論文與官方教學。選好來源再按「建立教材與知識地圖」，沿用補充學習的取得、授權與分析流程。

確認範圍前不搜尋，選來源前不建立空教材。主題與已確認範圍保存在帳號，重開不會重送工作；重新規劃另開主題，保留原紀錄。找不到可用來源時可調整需求；部分來源取得失敗時，可重試或明確改選成功來源繼續。知識地圖的內容以實際選取來源為準，範圍大綱本身不當成教材證據。

## Podcast 同步畫面

播放器下方新增「同步畫面」頁籤。按「準備整份同步畫面」後，系統使用既有講稿與音訊，逐集建立對齊資料；音訊不重算。完成的集數可直接使用，未完成或失敗的集數會分別顯示，可取消及重試。

畫面呈現目前概念與原重點；有既有對照關係或明確步驟時，另經來源核對才顯示比較／流程。來源不足則保留原重點圖卡，不補造差異或順序。可點段落跳轉，暫停、快進／後退、倍速及切回前景皆跟隨同一音訊的實際播放位置。來源入口維持建立 Podcast 時的教材版本，不更新掌握度，也不提供影片匯出。
