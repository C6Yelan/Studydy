# 使用指南

[文件入口](../README.md) · [安裝與啟動](getting-started.md)

## 帳號與教材庫

開啟本機前端後註冊或登入。Email 作為不分大小寫的登入識別，密碼長度為 15–128 個字元；目前沒有驗證信、忘記密碼或第三方登入流程。

首頁顯示教材與學習摘要，從「我的教材」找到自己的教材。名稱搜尋只篩選目前教材庫，不建立分析工作。相同帳號在新瀏覽器登入後，可從伺服器找回教材與學習紀錄。

## 上傳與分析

1. 點「上傳教材」，選取一份或多份支援的文件。
2. 在來源確認頁檢查各檔案的轉換狀態、預覽與順序。
3. 轉換失敗時明確重試或移除該檔案；未就緒的來源不會被默默略過。
4. 確認這次來源後開始分析。系統整理 Evidence、提出觀念與關係、進行檢核，再發布地圖。
5. 若顯示部分結果或需要複核，先對照原文確認內容。

關閉頁面不會自動取消伺服器工作。分析失敗時依畫面提供的操作重試；有可用保存進度時會接續，不需要再次上傳相同檔案。

支援格式、容量及轉換定位精度見 [教材處理](materials.md)。

## 知識地圖與來源

地圖以選定觀念為中心顯示兩層鄰近關係。搜尋與學習導覽可找到畫布未顯示的觀念；畫布上限不會刪除原始知識結構。

選擇觀念後，詳情面板顯示重點、來源與學習入口。手機使用對話框呈現詳情。來源操作可開啟 PDF 對應頁或下載原始檔；非 PDF 的定位精度會依格式不同而異。

「複習重點」呈現既有作答所反映的待改善內容。瀏覽地圖、開啟來源或重新讀取進度不會生成新題。

## 題組練習

從觀念詳情開始或接續學習，再明確開始該觀念的題組。題數依可出題的教材重點決定；準備中可以離開，稍後回來讀取同一組題目。

選完所有已發布題目後整組交卷，再查看正誤、說明與來源。尚未交卷的選取不等於已保存答案。交卷回應遺失時使用畫面的查回操作；版本衝突時先同步，再確認重送。

不同觀念可以各自保存未完成題組。切換觀念不會替另一組交卷，也不會改變已發布題目的來源。

## 錯題補強與接續

結果頁列出待補強重點。閱讀來源後點「開始補強」，系統只針對目前仍待改善的重點準備新題。再次答錯仍可明確開始下一輪；不會自動無限出題。

本輪通過與長期掌握是不同指標。補強答對計入本次改善，不補足獨立掌握證據，詳見 [學習與評量](learning.md)。

重新整理或重新登入會恢復已保存題組與結果。結果頁的「下一個觀念」或完成操作由後端判定後套用，不由前端自行宣告完成。

## 更新、改名與刪除

在教材管理中可追加來源、重新命名或刪除教材。改名只影響顯示名稱，不變更教材身分與來源。

追加來源會建立新地圖版本；更新失敗或取消更新時，已發布地圖與學習紀錄仍保留。新版學習可以承接來源與內容皆未改變且無歧義的作答證據。

刪除整份教材會一併移除來源、地圖、題目及學習紀錄。畫面要求確認；正在處理的工作先記錄刪除意圖，再完成清理。不要把「取消這次更新」與「刪除教材」混為同一操作。
