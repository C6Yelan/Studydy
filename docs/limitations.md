## 部署與可重現性

部署使用 Linux 容器。應用依賴由映像提供；主機仍須提供 Docker、kernel namespace 能力，以及完整 AI 流程所需的 GPU 驅動與容器整合。Windows／macOS 未提供原生啟動流程。

Compose 初始化資料目錄及 DB，OCR 工具可下載指定 snapshot。架設者仍需提供模型服務位址、認證與主機 GPU 設定；這些命令不代表已在所有 Linux／WSL2 環境完成驗證。部署不強制使用 SSH 或 RunPod。

預設只對 loopback 開前端 port，並使用非 Secure cookie。公開服務仍須由架設者提供 TLS，設定相符的 public origin／Secure cookie 並檢查營運條件。

## 文件與 OCR

100 MiB 是單檔上限，不保證上限內的每份文件都能成功轉換。Office 字型、圖表、公式與版面可能改變；DOC／PPT 不提供推測的原生段落／投影片定位，DOCX 對照也可能有歧義。

Markdown 圖片不載入，raw HTML 不執行。受保護、損毀、包含禁止主動內容或外部 relationships 的文件可能被拒絕。

原生文字可讀不代表整頁內容完整。重要圖片區域仍可能需要 OCR；OCR 失敗或未恢復圖片內容時，保留可用文字與複核提示。像素定位、來源 hash 正確也不能證明 OCR 文字或語意完全正確。

子程序有 wall time 與資源上限；NPROC 是每 UID 的限制，不是每個工作的 aggregate process／memory quota。

## 模型與教學品質

目前不能宣稱模型品質已全面通過驗收。概念範圍、關係方向與依據、題目歧義、語言一致性等仍需人工對照來源確認。

教材語意審查的可用率門檻維持 85%；同時仍要求來源／版本綁定、完整 Path、如實回報失敗、私密答案保護、零觀察到的錯誤掌握判定及 runtime 可用性。這些是驗收要求，不表示目前版本已達標。

程式能攔下部分來源、字面值、結構、重複與答案不一致問題，但不能證明所有保留的 Claim／Relation 都正確。partial／needs_review 明示待複核，不應呈現為已驗收。

教材檢核採批次處理，目前不提出跨檢核批次的整合。保守的先備／字面值保護可能保留片段或拒絕合理改寫。

本輪答對、補強通過與長期掌握是不同概念；系統的掌握投影也不等於對真實學習成效的獨立證明。

修改模型、revision 或 prompt 後，需要重新驗證品質；先前或其他環境的結果不能自動代表目前版本。

## 資料與功能邊界

原始教材及持久資料留在部署主機。AI 操作會將必要 Evidence、語意內容或題目請求傳至設定的服務；應在提供教材前確認該服務的處理與存取範圍。

帳號目前沒有 Email 所有權驗證、重設密碼、OAuth 或 MFA。登入 Email 只是識別，不代表信箱已驗證。

既有教材重整提供 API，尚無獨立 UI 操作。關閉頁面不會取消伺服器工作，取消也不保證停止外部服務已在途的計算。

## 自動化覆蓋

回歸以合成來源、受控模型、隔離 DB 與瀏覽器為主。真 API／DB 的「追加來源後，從 UI 接續先前學習」目前沒有接通的完整 browser fixture；後端追加測試、mock UI 與初次多來源 browser 不能合稱已驗證該整段流程。

Viewport 與非法輸入採代表性案例，未窮舉所有裝置、文件或輸入。測試通過提供程式回歸證據，不是全面安全、格式相容或模型品質保證。
