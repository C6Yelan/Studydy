# 限制

[文件入口](../README.md) · [測試](testing.md)

## 部署

需要 Linux 容器、Docker 及 kernel namespace 能力；本機 OCR 另需 NVIDIA GPU、驅動與容器整合。資料檔案系統須支援 Linux 權限。Windows／macOS 沒有原生啟動流程，部署不綁定 SSH 或 RunPod。

預設網站只綁 loopback 並使用非 Secure cookie；公開服務需另配 TLS、public origin 與 Secure cookie。模型服務、認證及主機能力由部署者提供。

## 文件與擷取

單檔 100 MiB 上限不保證所有文件都可轉換。Office 字型、圖表、公式及版面可能改變；DOC／PPT 不提供推測的原始段落／投影片定位，DOCX mapping 可能有歧義。

Markdown 不載入圖片或執行 raw HTML。受保護、損毀或含禁止主動內容的文件可能被拒絕。DOCX／PPTX 只盡力取得公開 HTTP(S) 圖片；每次 DNS 與重新導向都拒絕內網、loopback、link-local 等非公開位址，並固定連線至已核對的 IP。非圖片、帶帳密的 URL 及下載失敗的素材略過，一般超連結與原始上傳檔保留。圖片準備完成後，Office 在斷網沙箱轉檔，因此預覽可能缺少外連素材；DOC／PPT 也不連網載入素材。外部下載限制維持連線／讀取等待最多 3 秒、共用下載時間預算 15 秒、單一素材 10 MiB、合計 40 MiB。新轉檔採 policy version 3，既有 PDF、mapping 與來源身分不重寫。

原生文字可讀不代表整頁內容完整。OCR 可能漏字或誤辨；來源 hash 與定位正確也不保證辨識文字或語意正確。

原生文字頁仍會產生 PNG；其 render hash、尺寸與座標參與現行 page Evidence 契約。沒有 OCR 呼叫不代表沒有渲染成本，按需渲染尚未導入。

子程序有時間及資源上限；NPROC 按 UID 計算，不是整個工作所有程序的合計配額。

研究讀取目前支援 PDF 與 HTML 正文；全文只有 Word 附件時回報格式不支援，不把介紹頁當正文。這不改變使用者上傳 Office 教材的轉檔支援。

## 圖片、音訊、影片與 YouTube

不支援 HEIC。圖片文字依賴 OCR，手寫、低解析度或斜拍照片可能漏字；JPEG 只處理 EXIF 旋轉，不處理鏡像（方向 5、7 只轉正、不翻回）。語音辨識可能聽錯專有名詞、混入簡體字或把背景音辨成文字，逐字稿沒有標點時段落較難閱讀；時間段以每句開始時間歸類，因此相鄰兩段可能有數秒重疊。辨識品質不是驗收保證，回查時以原音為準。

YouTube 讀取依賴 yt-dlp 與 YouTube 現行網頁，有服務條款灰色地帶，網站改版可能讓讀取失敗直到更新 yt-dlp。上傳者字幕可能是翻譯字幕（例如英文影片的繁中字幕），內容以字幕為準而非原音。已加入的 YouTube 影片之後若被刪除或改為私人，逐字稿與分析結果仍保留，但內嵌播放器無法播放。

## 模型與學習品質

Concept、Claim、Relation 及題目仍需人工對照來源，尤其是合併概念的適用範圍、關係方向與題目歧義。程式能檢查來源、字面值、結構、重複及答案一致性，不能保證所有語意正確。

新 Claim 的 `localized_meaning_v2` 按完整數量與單位比對，避免把獨立的 `1` 誤認為已由 `10` 保留；允許重複敘述去重與既有日期翻譯。已發布的 `localized_meaning`／`semantic_meaning` 沿用原讀取規則，不重寫舊 Claim 或 Revision。這仍無法驗證數值是否被放回正確對象與脈絡。

教材語意審查的驗收要求包括可用率至少 85%、來源／版本綁定、完整 Path、如實回報失敗、私密答案保護、零觀察到的錯誤掌握判定及 runtime 可用性；此門檻不代表產品已全面達標。

partial／needs_review 結果需複核，地圖與學習頁的品質提示尚未完整延續。概念整合可跨批合併等義內容；關係檢核仍只覆核兩端同時位於該批的既有關係，沒有一般性的跨批新關係發現階段。關係引用修正與重複關係合併通過測試，不代表跨批關係已完整覆核。先備與字面值保護可能保留片段或拒絕合理改寫。沒有合格候選時可能只發布部分題目。

模型覆核通過不代表全圖零重複，核心內容抽查也不代表整份教材已精修。後續修正以錯誤合併、資訊遺失或影響理解的具體問題為依據，不因局部成果可用而清除教材品質標記。

研究有單次輸入、下載與停滯檢查，概念整合有局部補正次數限制；兩者仍沒有持久化的整個工作總呼叫或總下載預算。持續得到新來源、容量拆批與跨批比較仍可能增加總成本。因此不能宣稱整體工作量已封頂。

已發布的 `semantic_calls`、`ocr_calls` 會包含接續或重用的工作量，研究的 `calls` 主要在成功返回後累計；它們不是本次實際計費請求數。審查與整合紀錄另有新呼叫及重用資訊，provider 紀錄可補充已觀察到的請求；回應遺失或供應端用量未提供時仍可能未知。token 估算與供應端回報用量應分開解讀，不能用單一計數宣稱費用或加速幅度。

練習答對、補強通過及長期掌握是不同指標。更換模型、revision 或 prompt 後須重新驗證，其他素材或環境的結果不能直接套用。

## 資料與功能

教材與持久資料保存在部署主機，AI 操作會傳送必要內容至設定服務。帳號沒有 Email 所有權驗證、忘記密碼重設（登入後可修改密碼）、OAuth 或 MFA；登入裝置清單的裝置名稱只依 User-Agent 粗略辨識瀏覽器與系統（App 內建瀏覽器等只顯示系統，0013 之前的登入顯示「未知裝置」），不記錄 IP 或地點。

教材重整只有 API 入口；關頁不會取消工作，取消也不保證停止在途推論。已刪除資源頁的操作入口及取消後文案仍有待改善。

## 測試覆蓋

自動化以合成來源、受控模型、隔離 DB 與瀏覽器為主，未窮舉所有裝置、文件或輸入。真 API／DB 的「追加來源後由 UI 接續原學習」尚無完整 browser fixture，不能把各層測試合稱同一端到端驗證。

測試通過提供程式回歸證據，不是全面安全、格式相容或模型品質保證。

保存的辨識文字無法量測原始發音準確度或現場打斷延遲；缺少原錄音時，文字理解重播不能當作聲學對照。有限術語樣本也不能代表其他唸法、環境噪音與真人聽感皆已驗收。

## Podcast

Podcast 使用 Luna 腳本與本機 CosyVoice 3 RL／原參考聲線與 V／W 指令生成；桌機與手機尺寸的瀏覽器檢查不能代替實體裝置及其他瀏覽器驗收。來源固定於建立時的 KS，原本的 `needs_review`／缺頁資料仍保留；自動來源核對與有效 WAV 不保證語意、術語發音或台灣口音全部正確，尚未完成人工音質驗收。

所有分集音訊與影片完成後才開放預覽。背景模型生成、資源排隊與生成 HTTP 回應沒有固定完成期限；使用者取消會傳到本機 provider 並停止子程序群組，晚到結果不得發布。工作存活時持續續租，租約只回收失聯 worker，不是生成上限。取消整份 Podcast 會刪除它；重試失敗影片會保留已完成影音。播放位置與實際收聽秒數保存在伺服器，跨裝置接續；離線期間累積超過單次 60 秒的收聽不採計。


講稿、引用、Voice context、Assessment handoff 與音訊正規化的工程測試不代表模型品質通過，驗證範圍見 [測試](testing.md#podcast-現行驗證範圍)。現行建立入口不提供 Quick／Full 模式，歷史欄位只供舊資料讀取。

細字幕只使用實測 Whisper 錨點，舊產物缺少細錨點時保留原 VTT，不自動重製。對齊不確定時可能合併讀句，不能保證所有字幕都落在理想長度，也不提供推估的逐字高亮。teaching scope、來源、Voice 與 Assessment authority 不隨字幕切分改變。

語意版面提供概念、比較、相鄰步驟及雙方訊息交換，沿用 60fps 2D renderer；不涵蓋任意分支圖、多人協定或原教材圖片。文字很密時仍須精簡或重新組織，中文換行與美感仍可改善。講稿經逐段原文核對、分鏡生成一次；核對由同一個模型（Luna）判斷，可能漏判或誤判，完全沒被引用的重點也不在核對範圍內，格式與來源驗證成功仍不代表語意或版面品質全面通過。

ASR 對部分縮寫仍可能重複或誤辨；有效 WAV、響度或辨識量測不能代替發音、弱音與自然度聽評。影片維持 60fps，不以低幀率的效能收益取代慢速播放呈現驗證。

背景問答、主題、補充研究與文件轉檔亦會續租。轉檔與音訊後製不設固定完成期限，保留轉檔沙箱資源限制、來源取消、子程序退出與輸出驗證；沒有可靠進度時不以安靜的 log 判定卡死。連線建立、健康檢查、外部下載、登入與 DB 等待仍保留各自的保護期限。

收到工作取消後，本機會中斷正在等候 provider 的 HTTP socket，並嘗試通知遠端；取消端點失敗不再讓本機讀取無限等待，但也不能據此宣稱遠端模型已停止。建立連線仍受原本 10 秒上限約束，取消通知仍受 5 秒上限約束；未取消且沒有可靠進度訊號的生成，仍不設任意完成期限。
