# 知識地圖工作區

依使用者確認，地圖以目前概念為中心顯示最多兩層，最多 30 個節點、60 條連線。
沒有整張大圖模式；canonical KS 保留完整資料供搜尋、學習導覽及來源回查。
這些是畫布顯示預算，不是模型品質門檻或硬體通用 SLA。

- 兩層卡片使用一致寬度、字級與間距，皆顯示名稱、兩行重點摘要及已有的學習狀態；點選後可閱讀完整詳情。
- 先選第一層，再選第二層；同層依 canonical 關係順序決定。多路可達的概念只顯示一次。
- 保留每個顯示節點連回中心的必要連線，再優先加入中心的其他關係及範圍內連線。
  不改關係方向／類型，也不因連線上限製造假的孤立節點。
- 若兩層候選範圍超過節點或連線預算，在畫布內顯示目前／總數與「尚有其他相關內容」提示。
  未顯示的概念仍可用搜尋或導覽選取；不是從原始資料刪除。
- 每次換中心重新計算兩層，不累加舊節點；第一次及換中心時適應畫面。每欄最多八張卡，避免過長直列。
- 左上角僅保留浮動學習導覽開關，左下角是放大、縮小、適應畫面，不新增工具列或模式按鈕。
- 點選才開右側詳情，手機沿用 modal；學習按鈕只放在概念詳情內。
- Dashboard 學習總覽、Document Tree 與「複習重點」保留，舊 Map 章節目錄維持移除。

開關同一概念詳情、重讀同版本進度不重置手動 viewport；resize 保持中心及縮放比例。
換 KS revision 清除舊選中 ID、viewport 與面板狀態。React Flow ResizeObserver 負責尺寸量測；
拓樸變動時待初始化完成後只批次更新一次連接點，不因尺寸回寫逐節點反覆重測。

API、schema、DB、模型與 learner authority 無變更。純瀏覽不發出產品寫入或模型請求；
明確學習操作及登入續期沿用既有契約。
