## 指定案例與目前狀態

主要補充案例為「【Demo】【Luna】生成式 AI 與可靠代理｜補充學習」，已定位為 73 頁教材，確切 ID 與版本見私人 `handoff-context.json`；它不是 64 頁問答教材，也不是名稱相近的「自編課堂版 v2」。

其既有研究是 `material-research/v2`，狀態 `selecting`、研究階段 `complete`，有 116 筆候選、未選取來源、沒有教材處理 run，也沒有現行已確認 scope。**這不代表追加教材已完成。** 保留舊研究與原檔，依現行需求確認流程接續或建立必要的新研究，不直接填資料繞過確認契約。既有需求為「AI Agent 怎麼知道該繼續嘗試，還是停下來問人？」；代理可在已授權測試中核對範圍並操作產品確認，不要求使用者每一步回來點選。

問答回歸使用私人清單指定的 64 頁、1,036 頁教材；其中已壓縮長對話固定在舊 1,000 頁版本。歷史問答不得用來驗證之後新增的 36 頁，資料定位不能只憑教材名稱或目前 head。

其他案例優先重用已授權教材，缺少基準才建立少量虛擬 PDF。原始需求轉換不需每題做 PDF；從主題建立教材要從 prompt 真正搜尋來源，不用預製 PDF 取代完整流程。

## 已確認的問答與語音線索

- 正常文字三題及短追問的核心內容可用。正常語音有多處辨識錯字，部分被上下文彌補；大型語音其中一題將「剛才」誤為陌生比較對象，後續回答未恢復正確指涉。
- 大型文字與語音都漏答 FAAI 門檻邊界。完整原文有 `rho_t > tau` 才修正、`rho_t <= tau` 保留原動作；不能把「等於」擅自修成「高於」。
- 另一題漏掉原文明確存在的同模型文件增量更新。取材重播可找回相關段落，但沒有保存所有當時的逐次模型輸入，不能把重播冒充完整歷史 trace。需兼查取材與審查過度拒絕。
- 99 筆保存引用與固定版本索引的文字／Evidence 綁定核對一致，這不是所有答案語意皆正確的證明。
- `voice.py` 與 Podcast 都呼叫同一 `/audio` provider，再用 `ops/podcast/synthesize.py`、`spoken_input.py`、`dialogue_audio_repair.py`。動態停頓已套用，主要缺口是句內符號／結構及問答段落資訊，不需另造一套語音架構。
- STT 為既有 faster-whisper 1.2.1／large-v3-turbo、CPU int8、beam 3、通用提示；沒有教材詞彙與近期主題提示，未傳遞辨識分數。先在既有能力內做對照，不將提高 beam 當成必然改善。
- 原始輸入錄音已清除，回答音訊仍可讀。聲學原因與實體麥克風、快語速、相近音及真人聽感需要少量代表音訊／人耳確認；受控或合成測試不能冒充這部分已通過。

## 驗收與交付要求

- 以原始需求、使用者確認的範圍與原文為依據，不讓生成後的概念表重新定義驗收標準。
- 主要要求漏掉、明確限制被違反、來源不符、無依據斷言、重要條件遺失或產物不可用須修正；命名與拆分差異、少量重複、非必要例子不足不作通用失敗門檻。
- 模型自評、JSON／HTTP 成功、固定分數與速度改善不能代替內容驗收。比較上下文成本時一併檢查漏選、誤去重及結果品質。
- 已通過且未受後續修改影響的案例不無限重測；有修改、失敗或未解疑慮才重跑或擴大。
- 最後列出實際改動、各項驗證、部署狀態、來源不可取得等外部限制，以及仍需真人確認的語音項；保留部分完成與未驗證的區別。
