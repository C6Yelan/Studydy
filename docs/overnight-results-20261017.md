## 兩條完整正式站流程

- **既有教材補充**：依「Agent 何時繼續、停止與求助」確認範圍，實際搜尋並選取 OWASP Agent Security、Act or Escalate、Loopjacking 三份來源，完成取得、轉檔、分析與追加；教材由 73 頁成為 113 頁。問答核對成本、校準、權限、有限重試與核准 A／實際 B 的定義；兩張概念卡及新版 Podcast 已產生並檢查。仍保留 `RELATIONS_REJECTED`、`SOURCE_REVIEW_SUGGESTED`，未把已拒絕的關係當成通過。
- **從主題建立教材**：從 HTTP 快取需求開始，經提案編輯與確認、實際搜尋、MDN 來源驗證及選材，完成 Conditional requests 與 Cache-Control 兩份來源、13 頁教材。問答確認 max-age、ETag、200／304 及 no-cache 例外；兩張概念卡與 Podcast 完成。沒有把 CDN／s-maxage 擴為獨立必學主題，必要的 shared／private 邊界仍保留。狀態維持 `SOURCE_REVIEW_SUGGESTED`。
- 兩條流程的五份匯入原檔均與來源集合及研究快照 hash 相符；集合與 bundle digest 驗證通過。新加入來源封存已確認範圍；HTTP 第一份來源在此修正前已發布，其舊 bundle 不追改 hash，第二份追加來源已封存範圍。
- 兩份最終 Podcast 的 WAV hash、單聲道 24 kHz／16 bit 與時長核對成功，分別約 244.51、345.74 秒；影片均完成 1920×1080。正式瀏覽器確認播放時間前進、暫停與章節跳轉；390px 手機及 1280px 桌面沒有橫向溢出。概念卡切換、PNG 匯出與 PDF 來源可用；未登入取得受保護的 PDF／影片回傳 401。這些檢查不代表人耳聽感通過。

## 本輪實際失敗與處理

- 補充提案最初被既有概念擴大：修正需求轉換並重新確認範圍。
- 文字轉檔把跳脫後的 `href=`／`src=` 範例誤判成外連：改為檢查實際 HTML 標籤與屬性。
- 字面值保護誤配跨段反引號、引號、Markdown 強調與合法中英日期順序：修正後重跑原教材相容性。HTTP 曾有八份模型回應未通過本機語意輸出驗證，失敗 run 保留，修正後完成來源追加。
- 相鄰原文使排除主題重新進入分析：新來源把確認範圍封存至 bundle，分析及審查都使用該範圍；既有 hash 不改寫。
- 補充 Podcast 初稿把正確機率說成錯誤機率：發現數學定義在選中重點附近、卻被上下文裁掉。修正同來源／同頁的定義補入與 provider 篩選；新版正確保留機率定義、成本條件、閾值方向、校準假設與偏差方向。初稿改名標示「未通過」並保留原稿／音訊，沒有以 ready 冒充內容通過，也未新增自動 AI 評分重寫迴圈。
- 最後查核發現既有清理機制未保留研究所引用的舊地圖：補上未刪除研究的 base revision 引用判斷，32 項相關回歸通過後部署。原 73 頁地圖從部署前備份精確恢復一筆，原 revision／內容及來源關係驗證通過，重建 899 段索引；目前 113 頁 head 未變。原始教材檔案一直保留。沒有還原整個產品 DB。
- 一項來源回歸的舊英文 fixture 不再符合現行中文語意要求：修正 fixture 後該項通過。前端新增補查控制曾造成一項版面失敗，移至既有 footer 後該項與兩項新互動測試通過。
