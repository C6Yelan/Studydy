# 學習與評量

[文件入口](../README.md) · [使用指南](usage.md) · [教材處理](materials.md)

## 學習與題組身分

同一使用者、教材與知識結構版本對應持久 StudySession。不同觀念可各自保留題組，同一 session／觀念只保留一組進行中的題組；讀取不建立 session 或重算答案。

題組的 owner、知識結構版本、觀念及成員決定作答授權，導覽焦點不改變授權範圍。

## 準備與發布

題數由觀念中可出題的重點決定。題組保存計畫、執行快照、逐題狀態與 lease；worker 在交易外生成候選，驗證後保存並發布。

生成器提出候選；獨立檢核只取得來源、題幹與重排選項，不接收答案鍵。發布要求唯一答案與候選正解一致、來源有效且不重複已發布題目。通過正確性檢查後才依品質提示排序，干擾選項較弱不等於無安全題。

公開 API 不暴露準備中的題目或私密答案。失敗可重試未完成題；已有可用題時可選部分發布，其餘重點維持未檢測。每組使用建立時封存的模型設定，調整設定不改寫已保存題組。

## 交卷

提交包含全部已發布題目的選項、expected_set_version 與 Idempotency-Key。少答、重複成員、無效選項或範圍不符都會拒絕整次提交。

答案、事件序號與題組完成狀態在同一交易保存，失敗全部回滾。後端依私密答案評分；相同意圖重播不重複計分，也不覆寫已保存答案。版本衝突須先同步，回應遺失可查回結果。

## 學習重點與概念完成

第一次檢測答對，該重點立即完成。答錯後需連續答對兩道不同題（依 semantic identity 判別）；再次答錯會重新累積。重點一旦完成，之後再次練習的錯誤不撤銷完成。原始 diagnostic／remediation、正誤與答案事件仍完整保留，不另形成掌握度 gate。

概念主要狀態只有「尚未開始／進行中／需要加強／已完成」。全部可檢測重點完成時，概念已完成；有錯題尚待完成則需要加強。題組的準備、失敗及本次練習結果不覆蓋概念狀態。測驗頁僅列出已有正式作答紀錄的概念，依既有完成狀態分為尚未完成與已完成；已完成概念提供「再次練習」；地圖側欄讀完完整重點後，可直接開啟或接續題組。

NO_SAFE_ASSESSMENT 或部分發布時省略的重點是系統能力限制，不算使用者答錯，也不形成永久補強 gate。有部分可檢測重點時，以這些重點判定該次完成；零可檢測時不自動完成，顯示「此概念目前無法提供可靠檢測」，允許繼續下一概念。已有題目而未作答的重點仍未完成。

完成狀態由 [learning_states.py](../backend/src/learning_adaptation/learning_states.py) 及歷史題組重建，不批次改寫過往答案。已完成 session 仍可開啟再次練習；單純閱讀或改變導覽焦點不重開 session。

## 恢復與版本承接

Progress 與 resume 使用同一 DB snapshot，核對 session、run、知識結構版本、題組成員與事件序號。URL 可定位原題組；讀取、刷新與重新登入不產生題目或答案事件。

下一步由後端進度決定，前端提交 guidance_revision 套用操作。更新教材後，來源、文字及區塊一致且可唯一匹配的重點能承接證據；變更或匹配有歧義時不承接。

承接不複製答案事件，也不修改原題目、正誤、時間或版本。原題組仍依其固定版本讀取。

## 概念圖卡

新卡組保存選材與知識結構版本，依序進行準備來源、AI 精簡、核對來源，再開啟卡組。進度以已完成觀念數呈現；關頁後背景工作繼續，失敗可重試未完成步驟。卡面文字以完整重點段落交給 Luna 精簡，不把 PDF 排版換行當成句界；每段產生一次，再由模型對照原文覆核一次，通過即採用，有問題則保留原文並保存覆核理由，不反覆重寫或追加審查。程式只檢查卡面格式與來源對應，不以數字字串完全一致判斷語意。不同觀念的必要原文依 token 預算合併小批次，相同原文在同教材、版本與政策內重用已覆核結果，避免重複傳送；已完成的觀念可續接。精簡只作用於原版型的說明文字，不改寫原始重點、Evidence、欄位順序或公式／程式碼。圖卡讀取同一保留版本的概念、重點、關係與 Evidence，不另建知識來源。預覽以 Canvas 直接繪製 1200 × 760 PNG，呈現教材中的先備、組成、應用、實例或對照關係；先備僅表示學習依賴，對照不推定優劣。缺乏可回查關係時，以概念與教材重點的小型結構圖呈現，不推測流程或因果。程式碼／公式取自既有重點，節錄會標示，完整條件與來源保留在「完整重點與來源」。

`needs_review` 在完整重點保留待確認提示。圖卡不會因繪製完成而取得品質驗收。保存版本讀取失敗時可重新讀取，不改用目前的教材版本；來源入口沿用該版本的 resolver。預覽、放大與下載共用同一張 PNG，不產生或解碼中間 SVG。同一次開啟卡組時，已繪製的 PNG 與排版依內容物件快取，切卡、洗牌與重新瀏覽會重用；讀入新版內容時重新產圖，失敗不留快取。圖片只在瀏覽器記憶體中重用；經核對的卡面文字隨卡組保存，只在同一擁有者、教材版本與精簡政策內重用。舊卡組保留原文顯示，不因升級自動觸發模型。不執行教材提供的 HTML、JavaScript 或 SVG。

卡面使用固定比例，集中顯示標題、核心說明、至多四個重點節錄與小圖。左側選概念，右側單卡預覽；完整條件與全部來源可另開詳細面，不以節錄取代教材。

## 教材文字與語音問答

文字與語音辨識後的問題共用 RAG 路徑。Luna 先依問題與必要追問上下文規劃一到四組精確檢索術語，再連同原問題查詢已保存的索引；查詢規劃不提供答案依據。檢索補鄰接內容與同概念資料，完全相同的原文去重但保留各來源。對話按 token 預算保留近期完整輪次，超額時才將較早內容與既有摘要合併壓縮；摘要與近期對話共用原歷史預算，沒有固定三輪限制。摘要保留目標、條件、修正與未解問題，只供還原指涉，教材事實仍須檢索原文支持。原始對話不刪除，摘要為有損壓縮，不保證所有舊細節均能保留。

Luna 逐段回答並引用本輪原文，獨立核對各段。核對可刪去未支持的附加主張或修正適用範圍，保留有依據的核心步驟；不能藉修正新增事實。資料不足時最多補查一次，同時保留回答與核對階段提出的精確術語，各子問題保有取材名額。保留已通過核對的回答，具體指出未補足部分，不因一個次要缺口丟棄全部答案。新回答保存 `material-answer/v2` 與 passage 引用，不重建舊 claim 索引或轉接舊回答。

問答原文預算為 7,500 個估算 token；歷史合計 1,200，其中摘要最多 550；整次提示與輸出 schema 上限 12,000，另保留模型回答空間。摘要按批次保存處理位置，後續只壓縮新超額的輪次，不重送全部舊對話。使用 o200k 作估算，不把它當 Luna 實際 tokenizer 用量。取材、模型呼叫（含摘要）、各次輸入估算及壓縮前後歷史大小保存在回答的診斷欄位，不顯示給一般學習操作。

錄音先辨識文字，再走同一問答路徑；純文字不呼叫 TTS。答案朗讀失敗時保留文字與引用，重試只重做語音。取消與離開頁面沿用既有媒體清理與工作租約，不跨帳號保留音訊。

Podcast 依選定概念及關係規劃分集，透過同一索引取得各集引用與同頁鄰接脈絡。原文區塊只放一次，來源編號連回所選概念；與原文完全相同的重點不再重複放入提示，獨立摘要則保留。必要原文全部保留後，再以剩餘容量補鄰接內容；非連續片段明示缺口。不掃描整份教材作每集 context，不因容量不足截斷必要引用或更動既有腳本。

分集保留完整重點，以每集至多 32 個來源重點、8,000 個原文估算 token、10,000 個來源與脈絡合計估算 token 規劃，不再以 2,400 字元拒絕長重點。單一重點的必要原文仍無法容納時，回報 `PODCAST_SOURCE_TOO_LARGE`。教材索引建立成功不代表任意概念選取都能生成 Podcast；模型品質仍須檢查實際講稿與引用。
